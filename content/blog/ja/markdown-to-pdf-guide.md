## なぜ Markdown を PDF に変換するのか？

Markdown は執筆にはとても優れた形式ですが、共有や保管には PDF のほうが向いている場面がたくさんあります。就職活動には整った履歴書が必要です。クライアントは提案書を誰でも開ける読み取り専用の形式で受け取りたいと考えます。学校は印刷できる形での提出を求めます。PDF はどのデバイスや OS でも同じように表示されるため、ビジネス文書の標準になっています。

問題は、Markdown がそもそも「ソース」の形式だということです。構造と内容は定義しますが、見た目についてはほとんど何も決めていません。Markdown を PDF に変換するには、そのギャップを埋めるツールが必要です。構造化されたテキストを受け取り、適切な組版、改ページ、ヘッダー、フッター、余白をつけて描画してくれるツールです。

このガイドでは、代表的な変換方法を紹介し、それぞれの長所と短所を比較したうえで、きれいに仕上げるための実践的なコツをお伝えします。

## 方法 1：コマンドラインツール

### Pandoc

Pandoc は文書変換の万能ツールです。数十種類の入力・出力形式に対応しており、Markdown から PDF への変換もできます。

Pandoc で Markdown を PDF に変換するには、LaTeX ディストリビューション（TeX Live や MiKTeX など）をインストールしておく必要があります。Pandoc は PDF 生成の中間ステップに LaTeX を使うためです。

```bash
# 基本的な変換
pandoc document.md -o document.pdf

# 余白を指定
pandoc document.md -o document.pdf -V geometry:margin=1in

# 目次を付ける
pandoc document.md -o document.pdf --toc

# シンタックスハイライトのスタイルを指定
pandoc document.md -o document.pdf --highlight-style=tango
```

**長所：** 非常に高機能でカスタマイズ性が高く、LaTeX の数式に対応し、無料のオープンソース。

**短所：** LaTeX のインストール（数 GB）が必要、高度なカスタマイズは学習コストが高い、コマンドライン専用。

### wkhtmltopdf

WebKit のレンダリングエンジンで HTML を PDF に変換するツールです。Markdown を一度 HTML に変換してから渡します。

```bash
# Markdown を HTML に変換してから PDF に変換
pandoc document.md -o document.html
wkhtmltopdf document.html document.pdf
```

**長所：** CSS でスタイルを指定でき、おなじみの Web の描画方式を使える。

**短所：** 2 段階の手順が必要、複雑なレイアウトが苦手、プロジェクトはすでに積極的にメンテナンスされていない。

### md-to-pdf

Puppeteer（ヘッドレス Chrome）を使って Markdown を PDF に変換する Node.js 製のツールです。

```bash
npm install -g md-to-pdf
md-to-pdf document.md
```

Markdown ファイルの先頭に設定ブロックを書くか、別の設定ファイルを使って出力をカスタマイズできます。

**長所：** CSS でスタイルを指定でき、コードのハイライトがきれいで、開発も活発。

**短所：** Node.js が必要、Puppeteer のダウンロードサイズが大きい、ページレイアウトの制御が限られる。

## 方法 2：オンライン変換サービス

ブラウザ上で直接 Markdown を PDF に変換できるサイトもいくつかあります。

- **Dillinger**（dillinger.io）：PDF 書き出し機能付きの Web 版 Markdown エディタ。
- **MarkdownToPDF.com**：ドラッグ＆ドロップで使えるシンプルな変換サービス。
- **CloudConvert**：複数ファイルの一括変換に対応。

たまに使う程度ならオンライン変換は便利ですが、トレードオフもあります。内容を第三者のサーバーにアップロードすることになるため、機密性の高い文書では不安が残ります。書式のオプションも限られていることが多く、最終的な見た目をほとんど調整できません。

## 方法 3：printmd を使う

[printmd](https://printmd.app) は、Markdown を美しい PDF に変換するために作られた専用ツールです。ブラウザ拡張機能とデスクトップアプリとして動作し、ファイルをどのサーバーにもアップロードせずローカルで処理します。

### ステップごとの手順

**ステップ 1：printmd をインストール**

Chrome ウェブストアから printmd のブラウザ拡張機能をインストールするか、公式サイトからデスクトップアプリをダウンロードします。

**ステップ 2：Markdown を書く**

好きなテキストエディタで Markdown 文書を作成します。たとえば次のような内容です。

```markdown
# プロジェクト提案書

## エグゼクティブサマリー

本書では、顧客ポータルのリニューアルに向けた
進め方について、スケジュール、予算、
期待される成果を含めて説明します。

## スケジュール

| フェーズ | 期間  | 成果物         |
|----------|-------|----------------|
| 調査     | 2 週間 | 要件定義書     |
| 設計     | 3 週間 | UI モックアップ |
| 開発     | 6 週間 | 動作する試作品 |
| テスト   | 2 週間 | QA レポート    |

## 予算

総費用の見積もりは **$45,000** で、
内訳は次のとおりです。

- デザイン：$12,000
- 開発：$25,000
- テスト：$5,000
- プロジェクト管理：$3,000
```

**ステップ 3：printmd で開く**

Markdown ファイルを printmd で開きます。PDF がどのように仕上がるかを正確に示すライブプレビューが表示されます。

**ステップ 4：レイアウトを調整する**

用紙サイズ（A4、Letter など）、余白、フォント、文字サイズ、配色などを調整します。printmd には適切な初期設定が用意されていますが、細かい部分まで調整できます。

**ステップ 5：PDF に書き出す**

「PDF出力」ボタンをクリックすると PDF が生成されます。ファイルはお使いのパソコン上で作成されるため、内容が外部に出ることはありません。

### printmd が向いている理由

printmd は Markdown から PDF への変換作業のために設計されています。汎用の変換ツールが苦手とする、よくある悩みにも対応します。

- **改ページ**：見出しだけがページの下端に取り残され、続きの本文が次のページに送られるのを自動で防ぎます。
- **コードブロック**：シンタックスハイライト付きのコードブロックがページの途中で切れません。
- **表**：罫線と配置が整った、すっきりした表を描画します。
- **画像**：画像のサイズと配置をページの流れに合わせて適切に調整します。

## 方法 4：エディタの拡張機能

多くの人気エディタには、標準機能や拡張機能による PDF 書き出しがあります。

### VS Code

yzane 氏による拡張機能「Markdown PDF」を使うと、エディタから直接 Markdown ファイルを PDF に変換できます。

1. VS Code のマーケットプレイスから拡張機能をインストールします。
2. Markdown ファイルを開きます。
3. コマンドパレットを開きます（`Ctrl+Shift+P` または `Cmd+Shift+P`）。
4. 「Markdown PDF: Export (pdf)」を検索して実行します。

### Typora

Typora には「ファイル > エクスポート > PDF」から使える PDF 書き出し機能が標準で入っています。独自のレンダリングエンジンを使い、カスタム CSS テーマにも対応しています。

### Obsidian

Obsidian はコア機能として PDF 書き出しを提供しています。ノートを開き、三点メニューをクリックして「PDF にエクスポート」を選びます。

## プロ品質に仕上げるコツ

### フロントマターでメタデータを指定する

多くの変換ツールは YAML フロントマターを読み取って文書のプロパティを設定します。

```markdown
---
title: "2024 年第 4 四半期レポート"
author: "Jane Smith"
date: 2025-01-15
---
```

### 見出しの階層に気を配る

見出しは順番どおりに使いましょう。`##` から `####` へ飛ばしてはいけません。見出しの階層が整っていれば、論理的な目次を持つ構造のしっかりした PDF になります。

### 必要な場所に改ページを入れる

明示的な改ページに対応しているツールもあります。printmd やほかのいくつかの変換ツールでは、次のように書けます。

```markdown
<div style="page-break-after: always;"></div>
```

ツールによっては次の書き方も使えます。

```markdown
---

<!-- pagebreak -->
```

### 画像を最適化する

大きな画像は変換を遅くし、PDF のファイルサイズを膨らませます。画像は文書内で表示される最大幅に合わせて縮小しましょう。A4 や Letter サイズの文書なら、幅 800〜1200 ピクセルあれば十分です。

### まずは短い文書で試す

50 ページの文書を変換する前に、1 ページのサンプルで設定を試しましょう。余白やフォントなどのレイアウトを調整するときの時間を節約できます。

### 書式を統一する

文書全体で同じ書き方を守りましょう。箇条書きにハイフンを使うなら、途中でアスタリスクに切り替えないことです。ソースが一貫していれば、出力も一貫します。

## まとめ

Markdown から PDF への変換は、難しく考える必要はありません。たまに簡単な変換をするだけなら、エディタの拡張機能やオンラインツールで十分です。レイアウトに細かな要件があるビジネス文書なら、printmd や Pandoc のような専用ツールで必要な調整ができます。

大切なのは、自分の作業スタイルに合ったツールを選ぶことです。ターミナル中心で作業するなら Pandoc に勝るものはありません。依存関係をインストールせずに、プレビューを見ながらすばやく書き出したいなら printmd が最適です。どのツールを選んでも基本は同じです。きれいで構造の整った Markdown を書けば、変換は自然とうまくいきます。
