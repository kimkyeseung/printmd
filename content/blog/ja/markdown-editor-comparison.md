## 自分に合った Markdown エディタを見つける

Markdown エディタ選びは、意外と個人の好みに左右されるものです。邪魔にならない、集中できる環境を求める人もいれば、拡張機能やプラグインでカスタマイズできる多機能な IDE が必要な人もいます。ローカル保存とプライバシーを重視する人もいれば、リアルタイムの共同編集やクラウド同期を求める人もいます。

うれしいことに、2025 年にはどのカテゴリにも優れた選択肢があります。困ったことに、選択肢が多すぎて、すべてを比べるのは大変です。

このガイドでは人気の Markdown エディタ 6 つを取り上げ、長所と短所、向いている使い方、価格を比較します。読み終えるころには、どのエディタが自分の作業スタイルに合うかがはっきりわかるはずです。

## Visual Studio Code

### 概要

VS Code は Markdown 専用エディタではなく、汎用のコードエディタです。ただし Markdown のサポートが非常に優れています。すでに VS Code でコードを書いている開発者なら、同じツールで Markdown も編集するのはごく自然な流れです。

### 主な機能

- Markdown プレビューを標準搭載（分割画面での編集）
- 豊富な拡張機能（Markdown All in One、Markdown PDF、markdownlint）
- 変換コマンドを実行できる統合ターミナル
- バージョン管理のための Git 連携
- 多言語対応とシンタックスハイライト
- 設定やテーマによるカスタマイズ

### Markdown 向け拡張機能

**Markdown All in One** 拡張機能は、欠かせない機能を追加してくれます。

- 書式設定のキーボードショートカット（太字は `Ctrl+B`、斜体は `Ctrl+I`）
- 目次の自動生成
- `Alt+Shift+F` での表の整形
- Enter キーでのリストの自動継続
- KaTeX による数式のサポート

**markdownlint** は、よくある Markdown の書き方の問題を検出し、文書全体で書式を統一します。

### 長所

- 無料のオープンソース
- 膨大な拡張機能のエコシステム
- 開発者にはおなじみ
- 強力なファイル横断検索
- 優れた Git 連携

### 短所

- Markdown 専用ではないため、快適に使うには拡張機能の設定が必要
- プレビューは実用的だが、専用エディタほど洗練されていない
- ちょっとしたメモには重く感じることがある
- WYSIWYG モードがなく、常に生の構文が見える

### こんな人におすすめ

コードとドキュメントをひとつのエディタで書きたい開発者。Git と連携したドキュメント作成フローが必要なチーム。

### 価格

無料のオープンソース。

## Typora

### 概要

Typora はユニークなアプローチをとっています。入力と同時に構文を隠す WYSIWYG 型の Markdown エディタです。`## 見出し` と入力するとすぐに見出しとして表示され、`**太字**` と入力するとアスタリスクが消えて文字が太字になります。このライブプレビューとソースコードモードは切り替えられます。

### 主な機能

- 本格的な WYSIWYG の Markdown 編集
- 入力と同時に即座にレンダリング
- 内蔵テーマ（CSS によるカスタムテーマにも対応）
- PDF、HTML、Word、EPUB、LaTeX などへの書き出し
- 行と列を視覚的に操作できる表エディタ
- 集中して書けるフォーカスモードとタイプライターモード
- 文書内を移動しやすいアウトラインパネル
- コピー＆ペーストに対応した画像の取り扱い

### 長所

- もっともすっきりとした、洗練された Markdown 編集体験
- 分割画面が不要で、プレビューがそのままエディタ
- 構文を見ずに Markdown のメリットを得たいライターに最適
- 軽快で高速
- 美しい標準テーマ

### 短所

- 買い切りの有料ソフト（無料ではない）
- VS Code と比べるとプラグインのエコシステムが小さい
- クラウド同期は内蔵されていない（Dropbox や iCloud などのサービスに依存）
- リアルタイムの共同編集はできない
- コードを大量に書く作業にはあまり向かない

### こんな人におすすめ

すっきりと集中できる執筆環境を求めるライター、ブロガー、学生。WYSIWYG が好きで、Markdown ファイルの移植性も手に入れたい人。

### 価格

$14.99（買い切り、無料試用あり）。

## Obsidian

### 概要

Obsidian は単なる Markdown エディタではありません。プレーンな Markdown ファイルの上に構築されたナレッジ管理システムです。最大の特長は双方向リンクで、ノート同士をリンクすると、Obsidian がそのつながりを視覚的なグラフで管理してくれます。

### 主な機能

- ノート間の双方向リンク（`[[ノート名]]` 記法）
- ノートのつながりを表示するグラフビュー
- ローカルファーストの保存（ファイルは自分のパソコンに）
- 豊富なコミュニティプラグイン（1000 以上）
- 視覚的なブレインストーミングのためのキャンバスビュー
- 日記に使えるデイリーノート
- タグ、フォルダ、検索による整理
- 複数のノートを同時に表示できる分割ペイン

### 長所

- リンクとグラフビューによる強力なナレッジ管理
- ローカルファースト：データは自分のパソコンに残る
- 膨大なプラグインのエコシステム
- テンプレートやワークフローを共有する活発なコミュニティ
- ほかのどのエディタでも開けるプレーンな Markdown ファイル
- CSS やプラグインで自由にカスタマイズできる

### 短所

- デバイス間の同期には有料プランかサードパーティのツールが必要
- 高度な機能（Dataview、テンプレートなど）は習得に時間がかかる
- プレビューモードと編集モードが分かれている（ライブプレビューモードで解消されつつある）
- 一部のコミュニティプラグインは不安定なことがある
- モバイルアプリはデスクトップ版ほど洗練されていない

### こんな人におすすめ

研究者、学生、そして自分だけのナレッジベースを作りたいすべての人。アイデア同士のつながりを大切にし、ノートの関係を目で見て確かめたい人。

### 価格

個人利用は無料。Sync：月 $4。Publish：月 $8。商用利用：1 ユーザーあたり年 $50。

## Notion

### 概要

Notion はワークスペースツールで、Markdown 風の構文は数ある入力方法のひとつです。純粋な Markdown エディタではなく、コンテンツは独自の形式で保存され、ブロックベースのインターフェースで表示されます。ただし Markdown のショートカットを入力すると、すぐに書式付きのブロックに変換されます。

### 主な機能

- Markdown ショートカットに対応したブロックエディタ
- データベース、カンバンボード、カレンダー、ギャラリー
- リアルタイムの共同編集
- よく使う文書のテンプレート
- Web 上のコンテンツを保存する Web クリッパー
- ほかのツールと連携するための API
- AI ライティングアシスタント

### 長所

- 優れたリアルタイムの共同編集
- 多用途：メモ、Wiki、プロジェクト管理、データベース
- レイアウトをカスタマイズできる美しいインターフェース
- 共有ワークスペースのためのチーム機能
- Markdown ショートカットですばやく書ける

### 短所

- 本当の Markdown ではない：コンテンツは Notion 独自の形式で保存される
- インターネット接続が必要（オフラインモードは限定的）
- データは Notion のサーバーに保存される
- Markdown への書き出しは完全ではない（書式が失われることがある）
- ワークスペースが大きくなると動作が重くなることがある
- 機密性の高い内容ではプライバシー面の懸念がある

### こんな人におすすめ

ドキュメント、プロジェクト管理、データベースを組み合わせた共同作業の場が必要なチーム。プレーンテキストのファイルにこだわらず、Markdown 並みの速さで書きたい人。

### 価格

個人利用は無料（制限あり）。Plus：月 $8。Business：1 ユーザーあたり月 $15。Enterprise：要問い合わせ。

## printmd

### 概要

printmd は、Markdown を美しいレイアウトの PDF に変換することに特化したツールです。万能のエディタを目指すのではなく、「Markdown で書いて、そのまま印刷できるプロ品質の文書を作る」という作業に磨きをかけています。

### 主な機能

- 仕上がりの PDF と同じ見た目のライブプレビュー
- プロ品質の組版とレイアウト
- 複数のテーマとカスタマイズオプション
- コードブロックのシンタックスハイライト
- 改ページを考慮した表のレイアウト
- ローカル処理（ファイルがパソコンの外に出ない）
- ブラウザ拡張機能とデスクトップアプリ
- フロントマターのメタデータに対応

### 長所

- Markdown から PDF への変換作業のために作られている
- 設定なしでプロ品質の出力が得られる
- プライバシー重視：ローカル処理のみ
- 改ページ、ヘッダー、フッターを賢く処理する
- シンプルで直感的なインターフェース

### 短所

- 汎用的な編集ではなく PDF 出力に特化している
- 本格的なエディタと比べると機能は少なめ
- 実際の執筆はテキストエディタと組み合わせて使うのがベスト

### こんな人におすすめ

Markdown を PDF に変換する機会が多いすべての人。課題を提出する学生、レポートを作成するビジネスパーソン、クライアント向けのドキュメントを作る開発者などです。今使っているエディタの代わりではなく、一緒に使うツールです。

### 価格

最新の料金は [printmd.app](https://printmd.app) をご覧ください。

## StackEdit

### 概要

StackEdit はインストール不要のブラウザ版 Markdown エディタです。すべてブラウザ上で動作し、Google ドライブ、Dropbox、GitHub と同期できます。

### 主な機能

- インストール不要（ブラウザで動作）
- ライブプレビュー付きの分割画面エディタ
- Google ドライブ、Dropbox、GitHub、GitLab との同期
- Service Worker によるオフライン対応
- 共同編集
- UML 図、数式（KaTeX）、楽譜に対応
- テーマや拡張機能によるカスタマイズ

### 長所

- 準備不要：ブラウザを開けばすぐに書ける
- 複数のクラウドサービスと同期できる
- ブラウザがあればどのデバイスでも使える
- Markdown 初心者向けの WYSIWYG ツールバー
- 無料で使える

### 短所

- ブラウザが必要（ネイティブアプリではない）
- とても長い文書では動作が遅くなることがある
- デスクトップエディタに比べてカスタマイズ性が低い
- オフライン作業はブラウザのストレージに依存する
- 最新のエディタと比べるとインターフェースが古く感じる

### こんな人におすすめ

何もインストールせずに手早く Markdown を編集したい人。Google ドライブや GitHub と連携した共同執筆。慣れないパソコンで使う予備のエディタとして。

### 価格

無料。拡張機能付きの StackEdit Pro は月額サブスクリプションで利用できます。

## 選び方

### 自分に問いかけてみましょう

1. **主な用途は何か？** メモ、技術文書の執筆、ドキュメント作成、それとも PDF 作成？
2. **共同作業は必要か？** ほかの人とリアルタイムで編集するのか、ひとりで作業するのか？
3. **データのプライバシーはどれほど重要か？** ローカルファーストか、クラウド保存でもかまわないか？
4. **開発者か？** Git 連携やコーディング機能は必要か？
5. **予算はどのくらいか？** 無料ツールにするか、使い心地のためにお金を払うか？

### 判断の目安

- **「コードもドキュメントも書く」**：Markdown 拡張機能を入れた **VS Code**。
- **「とにかくすっきりした環境で書きたい」**：**Typora**。
- **「ナレッジベースを作りたい」**：**Obsidian**。
- **「チームで共同作業したい」**：**Notion**。
- **「Markdown からプロ品質の PDF を作りたい」**：**printmd**。
- **「何もインストールせずにすぐ編集したい」**：**StackEdit**。

### ツールを組み合わせる

Markdown に慣れた人の多くは、複数のツールを組み合わせて使っています。よくある流れは次のとおりです。

1. VS Code か Obsidian で**書く**（バージョン管理には Git）。
2. 技術に詳しくないメンバーとは Notion や Google ドキュメントで**共同作業**する。
3. 体裁の整った文書が必要になったら printmd で PDF に**変換**する。

ツールをひとつに絞らなければいけないというルールはありません。

## まとめ

最高の Markdown エディタとは、自分の作業スタイルに合ったエディタのことです。このリストのツールにはそれぞれ明確な強みがあり、誰にとっても「一番」というものはありません。主な用途に合うものを 2〜3 個選んで 1 週間ずつ使ってみて、作業スタイルに合わせて決めましょう。

Markdown のよいところは、ファイルを自由に持ち運べることです。Obsidian で始めて、あとから VS Code に乗り換えても、コンテンツはそのまま一緒についてきます。それがプレーンテキストの自由です。
