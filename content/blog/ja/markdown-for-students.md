## 学生が Markdown を学ぶべき理由

学生生活では、かなりの時間を書くことに費やします。講義ノート、レポート、実験レポート、研究論文、プレゼンテーション、試験対策ノート。どんなツールで書くかは、作業の効率と成果物の質に直結します。

多くの学生は、使い慣れているという理由で Microsoft Word や Google ドキュメントを使っています。これらのツールでも書けますが、不便な点もあります。起動が遅い、書式のオプションが多くて気が散る、バージョン間の互換性の問題がある、ファイルサイズが大きくて容量を圧迫する、などです。

Markdown はもうひとつの選択肢です。速く書けて、整理しやすく、出力の形式も柔軟です。さらに、卒業後も長く役立つスキルです。開発者、テクニカルライター、研究者、コンテンツクリエイターは毎日 Markdown を使っています。

Markdown を学ぶからといって、Word を完全にやめる必要はありません。特定の作業により向いた強力なツールを、道具箱にひとつ加えるということです。

## Markdown でノートを取る

### なぜノートに Markdown なのか？

一番のメリットはスピードです。講義中は情報をすばやく書き留める必要があります。Markdown の構文は軽いので、書式設定に使う時間が減り、話を聞くことに集中できます。見出し、リスト、強調はほんの数文字で書けます。

```markdown
# 第 12 回：機械学習の基礎

## 教師あり学習

- **ラベル付きデータ**で学習する
- 主な 2 つの種類：
  - *分類*：カテゴリを予測する（スパムかどうか）
  - *回帰*：連続値を予測する（住宅価格）

### 主なアルゴリズム

1. 線形回帰
2. 決定木
3. サポートベクターマシン（SVM）
4. ニューラルネットワーク

> 「すべてのモデルは間違っているが、役に立つものもある」 - George Box
```

Word で書式メニューをあちこちクリックするのと比べてみてください。Markdown では、入力するシンプルな記号から自然に構造が生まれます。

### ノートを整理する

授業ごとのフォルダ構成を作りましょう。

```
notes/
  2025-spring/
    cs301-algorithms/
      week01-intro.md
      week02-sorting.md
      week03-graphs.md
      resources.md
    math201-linear-algebra/
      week01-vectors.md
      week02-matrices.md
      problem-sets/
        ps01.md
        ps02.md
    eng102-writing/
      week01-thesis-statements.md
      essay-drafts/
        essay1-draft1.md
        essay1-draft2.md
```

プレーンテキストのファイルは小さく、検索しやすく、20 年後でもどんなエディタでも開けます。ノートがいつまでも使える状態で残ります。

### ノート同士をリンクする

Markdown でノートを取る大きな魅力のひとつが相互参照です。授業をまたいで関連する概念をリンクしましょう。

```markdown
## グラフアルゴリズム

関連：[グラフの行列表現](../math201-linear-algebra/week02-matrices.md#adjacency-matrices)

ダイクストラ法は最短経路を求める……
```

Obsidian のようなツールなら、双方向リンクやグラフの可視化でさらに一歩進み、ノートからつながりのあるナレッジベースを作れます。

## Markdown で課題を書く

### レポートの構成

Markdown では、フォントのことを気にする前に構成を考えることになります。これは学術的な文章を書くうえで、むしろメリットです。

```markdown
---
title: "ソーシャルメディアが政治的言論に与える影響"
author: "Jane Smith"
course: "政治学 201"
date: 2025-03-01
---

## はじめに

ソーシャルメディアは、市民が政治的な情報に
接する方法を根本から変えた。本レポートでは、
この変化を 3 つの観点から考察する……

## 情報の民主化

### 歴史的背景

ソーシャルメディアが登場する前、政治的な情報は
限られた経路でしか流れていなかった……

### 新しい状況

今日では、スマートフォンを持つ誰もが、
何百万人にも届く政治的な意見を発信できる……

## エコーチェンバーと分断

……

## おわりに

……

## 参考文献

1. Smith, J. (2023). *Digital Democracy*. Oxford Press.
2. Johnson, R. (2024). "Social Media and Voter Behavior."
   *Journal of Political Communication*, 42(3), 112-128.
```

### 引用と参考文献

引用の多い学術論文では、Markdown と Pandoc を組み合わせて BibTeX で引用を管理できます。

```markdown
最近の研究 [@smith2023; @johnson2024] では、
ソーシャルメディアの利用と政治的分断の拡大に
相関があることが示唆されている。
```

参考文献をまとめた `.bib` ファイルを用意します。

```bibtex
@article{smith2023,
  author = {Smith, Jane},
  title = {Digital Democracy},
  year = {2023},
  publisher = {Oxford Press}
}
```

Pandoc が正しい書式の引用と参考文献リストを生成します。

```bash
pandoc essay.md --citeproc --bibliography=refs.bib -o essay.pdf
```

## LaTeX 連携で数学・理科を書く

理系の学生にとって、Markdown の大きな強みのひとつが LaTeX の数式表記との連携です。ほとんどの Markdown レンダラーは、インライン数式とブロック数式に対応しています。

```markdown
## 解の公式

$ax^2 + bx + c = 0$ の解は次の式で求められる。

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

## オイラーの等式

数学でもっとも美しい式：

$$e^{i\pi} + 1 = 0$$

## 総和の例

最初の $n$ 個の自然数の和：

$$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$$
```

出力では、きちんと整った数式として表示されます。別の数式エディタは必要ありません。数式は本文の中にそのまま書けます。

### 化学式

化学を学ぶ学生向けに、化学反応式に対応した拡張 Markdown ツールもあります。

```markdown
メタンの燃焼：

$$\text{CH}_4 + 2\text{O}_2 \rightarrow \text{CO}_2 + 2\text{H}_2\text{O}$$
```

## 試験対策ノートを作る

### 単語カード風のノート

Markdown は、問題と答えの形式で勉強用の資料を作るのにも向いています。

```markdown
## 試験対策ノート：生物 中間試験

### 細胞分裂

**Q：体細胞分裂の各期は？**

1. 前期
2. 中期
3. 後期
4. 終期

**Q：体細胞分裂と減数分裂の違いは？**

- 体細胞分裂では同一の二倍体細胞が 2 個できる
- 減数分裂では遺伝的に異なる一倍体細胞が 4 個できる

### 遺伝

**Q：メンデルの分離の法則を説明せよ。**

生物は各形質について 2 つの対立遺伝子を持つ。
配偶子が形成されるとき対立遺伝子は分離し、
各配偶子は対立遺伝子を 1 つだけ持つ。
```

### まとめの表

勉強中に概念を比べるには、表がとても便利です。

```markdown
## 比較：原核細胞と真核細胞

| 項目     | 原核細胞 | 真核細胞                |
|:---------|:---------|:------------------------|
| 核       | なし     | あり                    |
| 大きさ   | 1-10 μm  | 10-100 μm               |
| DNA      | 環状     | 線状                    |
| 細胞小器官 | 少ない | 多い                    |
| 細胞分裂 | 二分裂   | 体細胞分裂／減数分裂    |
| 例       | 細菌     | 動物、植物              |
```

## 課題を提出用の形式に変換する

多くの先生は PDF か Word 形式での提出を求めます。Markdown なら変換の方法がいくつもあります。

### PDF に変換する

すっきりとした見栄えのよい PDF にしたいなら、printmd のようなツールが適切な組版とページレイアウトで変換してくれます。特に次のような場合に便利です。

- シンタックスハイライトが必要なコードを含む実験レポート
- 数式を含む研究論文
- 表や構造化されたデータを含むプロジェクトの企画書

```bash
# Pandoc を使う
pandoc assignment.md -o assignment.pdf

# 書式を指定する
pandoc assignment.md -o assignment.pdf \
  -V geometry:margin=1in \
  -V fontsize=12pt \
  --highlight-style=tango
```

### Word に変換する

先生から `.docx` ファイルでの提出を指定された場合：

```bash
pandoc assignment.md -o assignment.docx
```

### HTML に変換する

プレゼンテーションやオンラインのポートフォリオ用に：

```bash
pandoc assignment.md -o assignment.html --standalone --css=style.css
```

## 学生におすすめのツール

### Obsidian（無料）

つながりのあるノートを取るなら最適です。双方向リンク、グラフビュー、コミュニティプラグイン、ローカルファーストの保存といった機能があります。ノートは自分のものとして手元に残るプレーンな Markdown ファイルです。

### Visual Studio Code（無料）

拡張機能で Markdown を快適に扱える強力なエディタです。Markdown All in One 拡張機能を入れると、ショートカット、目次の生成、プレビューが使えるようになります。情報系を専攻しているなら、どのみちプログラミングで VS Code を使うことになるでしょう。

### Typora（買い切り）

ライブプレビュー付きの、すっきりとして集中できる Markdown エディタです。入力したものがすぐに表示されるので、シンプルなワープロのような感覚で使えます。生の構文を見ずに Markdown のメリットを得たい学生に向いています。

### Notion（学生は無料）

Markdown 風の構文に加えて、データベース、カンバンボード、共同編集機能を備えたハイブリッドなツールです。プロジェクト管理やグループワークにとても便利ですが、コンテンツは Notion のサーバーに保存されます。

### printmd

Markdown で書いた課題を整った PDF にしたいとき、printmd なら複雑な設定なしでプロ品質の出力が得られます。Markdown で書きつつ、書式の整った文書を提出する必要がある学生に特に便利です。

## はじめるためのヒント

1. **ひとつの授業から始める。** ノートがもっともシンプルな授業を選び、1 学期を通して Markdown を使ってみましょう。

2. **まずは 5 つだけ覚える。** 見出し、太字、斜体、リスト、リンクで、ノートに必要なことの 9 割はまかなえます。ほかは必要になったときに覚えれば大丈夫です。

3. **キーボードショートカットを使う。** ほとんどの Markdown エディタでは、Word と同じく `Ctrl+B` で太字、`Ctrl+I` で斜体になります。

4. **Git でバックアップする。** ノートを Git のリポジトリに入れましょう。変更履歴が無料で手に入り、GitHub や GitLab を通じてどのデバイスからでもノートを見られます。

5. **最初から完璧を目指さない。** まずは書き始めましょう。フォルダ構成、リンクの付け方、ツール選びはあとから変えていけます。大切なのは始めることです。

## まとめ

Markdown は、学業での文章作成をより速く、より整理された、持ち運びやすいものにしてくれる実践的なスキルです。あらゆる場面で Word の代わりになるわけではありませんが、ノート、試験対策ノート、技術的な課題など、すっきりした構成が活きる文書なら、これ以上のものはなかなかありません。

Markdown を学ぶのに必要な時間はわずか 1〜2 時間ほど。その見返りとして、大学生活からその先のキャリアまで役立つ執筆の流れが手に入ります。次の講義ノートから始めて、使い心地を試してみてください。
