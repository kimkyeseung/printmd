## 为什么在 Markdown 中使用表格？

表格是呈现结构化数据最有效的方式之一。对比图表、价格套餐、功能矩阵、日程安排和参考数据，都很适合用表格来展示。Markdown 表格在简单和实用之间取得了平衡，让你无需离开文本编辑器就能做出整洁易读的表格。

虽然 Markdown 表格不如 HTML 表格或电子表格强大，但足以应对写作者在文档、博客文章和项目报告中遇到的大多数场景。了解它的语法、能力和局限，能帮助你在任何 Markdown 文档中清晰地呈现数据。

## 基础表格语法

一个 Markdown 表格由三部分组成：表头行、分隔行和数据行。

```markdown
| 姓名    | 职位   | 所在地 |
|---------|--------|--------|
| Alice   | 开发者 | 纽约   |
| Bob     | 设计师 | 伦敦   |
| Charlie | 经理   | 东京   |
```

渲染效果如下：

| 姓名    | 职位   | 所在地 |
|---------|--------|--------|
| Alice   | 开发者 | 纽约   |
| Bob     | 设计师 | 伦敦   |
| Charlie | 经理   | 东京   |

竖线（`|`）用来分隔列，分隔行（短横线）把表头和表格主体分开。短横线的数量无所谓，只要至少有三个即可。

### 最简写法

源文本中的竖线不必对齐，下面这样写完全有效：

```markdown
|姓名|职位|所在地|
|---|---|---|
|Alice|开发者|纽约|
|Bob|设计师|伦敦|
```

不过，把竖线对齐能让原始 Markdown 更易读、更好编辑。大多数 Markdown 编辑器都有“格式化表格”命令，可以自动完成对齐。

### 首尾的竖线

在某些解析器中，最外侧的竖线严格来说是可以省略的：

```markdown
姓名 | 职位 | 所在地
--- | --- | ---
Alice | 开发者 | 纽约
```

但还是建议写上。这样表格结构更明确，也能确保在所有 Markdown 处理器中都兼容。

## 列对齐

可以在分隔行中用冒号控制列内文字的对齐方式：

```markdown
| 左对齐   | 居中对齐 | 右对齐   |
|:---------|:--------:|---------:|
| 文字     |   文字   |     文字 |
| 更多文字 | 更多文字 | 更多文字 |
```

- `:---` 或 `---` = 左对齐（默认）
- `:---:` = 居中对齐
- `---:` = 右对齐

这对数值数据尤其有用，右对齐能提高可读性：

```markdown
| 商品      | 数量    | 单价  | 合计        |
|:----------|:-------:|------:|------------:|
| 零件 A    |   50    | $2.99 |     $149.50 |
| 零件 B    |  120    | $1.50 |     $180.00 |
| 零件 C    |   30    | $8.75 |     $262.50 |
| **总计**  | **200** |       | **$592.00** |
```

## 表格内的格式

### 行内格式

表格单元格中可以使用标准的 Markdown 行内格式：

```markdown
| 功能     | 状态          | 备注                     |
|:---------|:-------------:|:-------------------------|
| 用户认证 | **已完成**    | 使用 OAuth 2.0           |
| 仪表盘   | *进行中*      | 预计在 `v2.1` 上线       |
| API v2   | ~~已取消~~    | 由 GraphQL 取代          |
| 移动应用 | `计划中`      | [查看路线图](#roadmap)   |
```

单元格内可以使用粗体、斜体、代码、删除线和链接。不过单元格内容要简洁。如果一个单元格需要写好几段，那表格可能就不是合适的形式了。

### 表格中的代码

行内代码在表格中效果很好：

```markdown
| 函数             | 说明             | 返回类型  |
|:-----------------|:-----------------|:----------|
| `getUser(id)`    | 按 ID 获取用户   | `User`    |
| `listUsers()`    | 列出所有用户     | `User[]`  |
| `deleteUser(id)` | 按 ID 删除用户   | `boolean` |
```

但是，代码块（三个反引号）不能放在表格单元格中。如果需要展示多行代码，请把它放在表格外面，并在表格中注明引用。

### 表格中的图片

小图片或图标可以放在表格单元格中：

```markdown
| 平台    | 图标                      | 状态   |
|:--------|:--------------------------|:-------|
| macOS   | ![mac](icons/mac.png)     | 支持   |
| Windows | ![win](icons/windows.png) | 支持   |
| Linux   | ![linux](icons/linux.png) | 测试版 |
```

图片要小。大图片会破坏表格的布局。

## Markdown 表格的局限

Markdown 表格有几个需要注意的局限：

### 不能合并单元格

无法横向或纵向合并单元格，没有相当于 HTML 中 `colspan` 或 `rowspan` 的写法。如果数据需要合并单元格，可以考虑改用 HTML 表格。

### 单元格不能换行

源文本中每一行表格都必须写在一行里。用标准 Markdown 语法，无法在单元格中换行。有几种变通办法：

- 用 `<br>` 换行：`单元格第 1 行<br>单元格第 2 行`
- 保持单元格简洁，把详细内容移到表格外面

### 不能嵌套表格

在标准 Markdown 中，表格不能嵌套在另一个表格里。

### 没有表格标题

标准 Markdown 表格不支持标题（caption）。可以手动添加：

```markdown
*表 1：各地区季度营收（单位：千美元）*

| 地区     | Q1   | Q2   | Q3   | Q4   |
|:---------|-----:|-----:|-----:|-----:|
| 北美     | $120 | $135 | $142 | $158 |
| 欧洲     | $89  | $94  | $101 | $112 |
| 亚太     | $67  | $73  | $81  | $95  |
```

### 无法控制宽度

Markdown 没有提供设置列宽的方法，列宽由内容决定。如果需要精确控制，就要用 HTML 或基于 CSS 的渲染工具。

## 变通办法与替代方案

### 在 Markdown 中使用 HTML 表格

当你需要 Markdown 表格无法提供的功能时，大多数 Markdown 处理器都接受行内 HTML：

```html
<table>
  <tr>
    <th rowspan="2">姓名</th>
    <th colspan="2">成绩</th>
  </tr>
  <tr>
    <th>数学</th>
    <th>科学</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>95</td>
    <td>88</td>
  </tr>
</table>
```

这样可以完全控制单元格合并、样式和布局，但也牺牲了 Markdown 表格最吸引人的可读性。

### 用定义列表替代

对于键值形式的数据，定义列表可能比表格更合适：

```markdown
项目名称
: printmd

版本
: 2.1.0

许可证
: MIT

平台
: 跨平台（macOS、Windows、Linux）
```

### 借助外部工具

对于需要排序、筛选或计算的复杂数据，可以考虑用脚本或电子表格生成 Markdown 表格。很多工具都能把数据导出为 Markdown 表格：

- **CSV 转 Markdown**：tableconvert.com 等在线转换器
- **Python**：`tabulate` 等库可以根据数据生成 Markdown 表格
- **VS Code 扩展**：“Markdown Table Prettify”和“Markdown Table Formatter”

## 让表格更整洁的技巧

### 保持格式一致

选定一种格式风格，并在整篇文档中坚持使用。确定对齐方式、是否写首尾竖线，以及空单元格如何处理。

### 保持简单

表格超过七八列就很难阅读了。可以考虑拆分成多个表格，或者换一种形式。

### 使用表格生成器

手动制作表格太繁琐时，可以用表格生成工具。有不少网站和编辑器扩展可以让你可视化地创建表格，再导出为 Markdown。

### PDF 输出中的表格

用 printmd 等工具把 Markdown 文档转换成 PDF 时，表格会得到特别处理。printmd 能解决以下常见问题：

- 跨页的表格会被干净地拆分，并重复显示表头
- 根据内容自动计算列宽
- 统一应用边框和内边距
- 保留 Markdown 源文件中的对齐设置

这意味着你只需用标准 Markdown 写表格，无需额外设置样式，也能放心地得到专业的 PDF 输出。

## 总结

Markdown 表格是在文档、博客文章和技术写作中呈现结构化数据的实用工具。虽然与 HTML 表格或电子表格相比有一些局限，但它在源文件中简洁易读，非常适合大多数常见场景。

掌握基础：表头行、用冒号对齐、行内格式和统一的样式。了解局限：不能合并单元格、单元格不能换行、无法控制宽度。遇到这些局限时，就改用 HTML 表格或重新组织内容。

有了这些技巧，你就能在任何 Markdown 文档中清晰、专业地呈现数据。
