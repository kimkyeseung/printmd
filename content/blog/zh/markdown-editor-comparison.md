## 找到合适的 Markdown 编辑器

选择 Markdown 编辑器是一件出乎意料地个人化的事。有些写作者想要一个不打扰人的无干扰环境；有些人则需要一个功能齐全、可以装扩展和插件、高度可定制的 IDE。有人看重本地优先的存储和隐私，也有人想要实时协作和云同步。

好消息是，2025 年每一类都有出色的选择。不太好的消息是，选择实在太多，逐一评估会让人眼花缭乱。

本指南对比六款流行的 Markdown 编辑器，分析它们的优缺点、理想用途和价格。读完之后，你应该能清楚地知道哪款编辑器最适合你的工作流程。

## Visual Studio Code

### 概述

VS Code 并不是专门的 Markdown 编辑器，而是一款通用代码编辑器，只是它对 Markdown 的支持非常出色。对于已经在用 VS Code 写代码的开发者来说，在同一个工具里编辑 Markdown 再自然不过。

### 主要功能

- 内置 Markdown 预览（分栏编辑）
- 丰富的扩展生态（Markdown All in One、Markdown PDF、markdownlint）
- 集成终端，可直接运行转换命令
- 集成 Git，方便版本控制
- 多语言支持与语法高亮
- 可通过设置和主题进行定制

### Markdown 专用扩展

**Markdown All in One** 扩展提供了不少必备功能：

- 格式化快捷键（`Ctrl+B` 加粗，`Ctrl+I` 斜体）
- 自动生成目录
- 用 `Alt+Shift+F` 格式化表格
- 按回车时自动续写列表
- 借助 KaTeX 支持数学公式

**markdownlint** 能发现常见的 Markdown 写法问题，让所有文档保持一致的格式。

### 优点

- 免费开源
- 庞大的扩展生态
- 开发者很熟悉
- 强大的跨文件搜索
- 出色的 Git 集成

### 缺点

- 并非专为 Markdown 打造，需要配置扩展才能获得好的体验
- 预览够用，但不如专用编辑器精致
- 用来记简单笔记显得有些笨重
- 没有所见即所得模式，始终看到的是原始语法

### 适合人群

想用同一个编辑器写代码和文档的开发者；需要与 Git 集成的文档工作流程的团队。

### 价格

免费开源。

## Typora

### 概述

Typora 的思路很独特：它是一款所见即所得（WYSIWYG）的 Markdown 编辑器，输入时会隐藏语法。输入 `## 标题`，它立刻渲染成标题；输入 `**粗体**`，星号会消失，文字变成粗体。你可以在这种实时预览和源代码模式之间切换。

### 主要功能

- 真正的所见即所得 Markdown 编辑
- 边输入边即时渲染
- 内置主题（也支持用 CSS 自定义主题）
- 可导出为 PDF、HTML、Word、EPUB、LaTeX 等
- 可视化管理行列的表格编辑器
- 专注模式和打字机模式，写作不受干扰
- 大纲面板，方便在文档中导航
- 支持复制粘贴的图片处理

### 优点

- 最简洁、最优雅的 Markdown 编辑体验
- 无需分栏，预览就是编辑器
- 适合想享受 Markdown 好处却不想看到语法的写作者
- 快速轻巧
- 默认主题很漂亮

### 缺点

- 需要一次性购买（不免费）
- 插件生态不如 VS Code 丰富
- 没有内置云同步（依赖 Dropbox、iCloud 等第三方服务）
- 不支持实时协作
- 不太适合大量写代码的工作

### 适合人群

想要简洁专注写作体验的写作者、博主和学生；喜欢所见即所得，又想要 Markdown 文件可移植性的人。

### 价格

$14.99（一次性购买，提供免费试用）。

## Obsidian

### 概述

Obsidian 不只是 Markdown 编辑器，而是一套建立在纯 Markdown 文件之上的知识管理系统。它的杀手级功能是双向链接：你可以把笔记相互链接起来，Obsidian 会在可视化的关系图中跟踪这些连接。

### 主要功能

- 笔记之间的双向链接（`[[笔记名]]` 语法）
- 展示笔记之间关联的关系图谱
- 本地优先存储（文件在你自己的电脑上）
- 丰富的社区插件生态（1000 多个插件）
- 用于可视化头脑风暴的白板（Canvas）视图
- 用于写日记的日记笔记
- 用标签、文件夹和搜索整理内容
- 分栏同时查看多篇笔记

### 优点

- 借助链接和关系图谱实现强大的知识管理
- 本地优先：数据保存在你自己的电脑上
- 庞大的插件生态
- 活跃的社区，分享大量模板和工作流程
- 纯 Markdown 文件，可以用任何其他编辑器打开
- 可通过 CSS 和插件高度定制

### 缺点

- 多设备同步需要付费订阅或第三方工具
- 高级功能（Dataview、模板等）有学习门槛
- 预览模式与编辑模式分开（不过实时预览模式弥补了这一点）
- 部分社区插件不够稳定
- 移动端应用不如桌面端精致

### 适合人群

研究人员、学生，以及任何在搭建个人知识库的人；重视想法之间的关联、想看到笔记之间如何相互关联的人。

### 价格

个人使用免费。同步服务：$4/月。发布服务：$8/月。商业使用：每位用户 $50/年。

## Notion

### 概述

Notion 是一款工作空间工具，类 Markdown 语法只是它众多输入方式之一。它不是纯粹的 Markdown 编辑器：内容以自有格式存储，并在基于块的界面中呈现。不过，你可以输入 Markdown 快捷语法，它们会立即转换成带格式的块。

### 主要功能

- 支持 Markdown 快捷语法的块编辑器
- 数据库、看板、日历和画廊
- 实时协作
- 常见文档类型的模板
- 用于保存网页内容的剪藏工具
- 用于与其他工具集成的 API
- AI 写作助手

### 优点

- 出色的实时协作
- 用途广泛：笔记、知识库、项目管理、数据库
- 界面美观，布局可定制
- 支持共享工作空间的团队功能
- Markdown 快捷语法让写作很快

### 缺点

- 不是真正的 Markdown：内容以 Notion 的专有格式存储
- 需要联网（离线模式有限）
- 数据保存在 Notion 的服务器上
- 导出为 Markdown 不够完美（可能丢失格式）
- 工作空间很大时可能变慢
- 处理敏感内容时存在隐私顾虑

### 适合人群

需要一个集文档、项目管理和数据库于一体的协作空间的团队；想要类似 Markdown 的写作速度，又不想局限于纯文本文件的人。

### 价格

个人使用免费（有限制）。Plus：$8/月。Business：每位用户 $15/月。Enterprise：定制报价。

## printmd

### 概述

printmd 是一款专注的工具，专为把 Markdown 转换成排版精美的 PDF 而设计。它不追求成为万能编辑器，而是专精于“用 Markdown 写作，生成可直接打印的专业文档”这一工作流程。

### 主要功能

- 与最终 PDF 完全一致的实时预览
- 专业的字体排版和版式
- 多种主题和定制选项
- 代码块语法高亮
- 表格排版，并妥善处理分页
- 本地处理（文件不会离开你的电脑）
- 浏览器扩展和桌面应用
- 支持 front matter 元数据

### 优点

- 专为 Markdown 转 PDF 的工作流程打造
- 无需配置即可获得专业的输出质量
- 注重隐私：只在本地处理
- 智能处理分页、页眉和页脚
- 界面简洁直观

### 缺点

- 专注于 PDF 输出，而不是通用编辑
- 功能比完整的编辑器少
- 最好搭配文本编辑器来完成实际的写作

### 适合人群

经常需要把 Markdown 转换成 PDF 的人：提交作业的学生、制作报告的职场人士、为客户生成文档的开发者。它可以和你现有的编辑器配合使用，而不是取而代之。

### 价格

最新价格请访问 [printmd.app](https://printmd.app)。

## StackEdit

### 概述

StackEdit 是一款无需安装的浏览器版 Markdown 编辑器。它完全在浏览器中运行，可以与 Google Drive、Dropbox 和 GitHub 同步。

### 主要功能

- 无需安装（在浏览器中运行）
- 带实时预览的分栏编辑器
- 与 Google Drive、Dropbox、GitHub 和 GitLab 同步
- 通过 Service Worker 支持离线使用
- 协同编辑
- 支持 UML 图、数学公式（KaTeX）和乐谱
- 可通过主题和扩展进行定制

### 优点

- 零配置：打开浏览器就能开始写
- 可与多种云服务同步
- 任何有浏览器的设备都能用
- 为 Markdown 新手提供所见即所得工具栏
- 免费使用

### 缺点

- 需要浏览器（不是原生应用）
- 文档很长时可能卡顿
- 定制性不如桌面编辑器
- 离线工作依赖浏览器存储
- 界面比现代编辑器显得过时

### 适合人群

不想安装任何东西、只想快速编辑 Markdown 的人；与 Google Drive 或 GitHub 关联的协作写作；在陌生电脑上临时使用的备用编辑器。

### 价格

免费。提供扩展功能的 StackEdit Pro 需按月订阅。

## 如何选择

### 先问自己这几个问题

1. **主要用途是什么？** 记笔记、技术写作、编写文档，还是制作 PDF？
2. **需要协作吗？** 与他人实时编辑，还是独自工作？
3. **数据隐私有多重要？** 坚持本地优先，还是可以接受云存储？
4. **你是开发者吗？** 需要 Git 集成和写代码的功能吗？
5. **预算是多少？** 只用免费工具，还是愿意为更好的体验付费？

### 决策参考

- **“我既写代码又写文档”**——用 **VS Code** 加 Markdown 扩展。
- **“我想要最清爽的写作体验”**——用 **Typora**。
- **“我在搭建知识库”**——用 **Obsidian**。
- **“我的团队需要协作”**——用 **Notion**。
- **“我需要把 Markdown 做成专业的 PDF”**——用 **printmd**。
- **“我想不装任何东西就快速编辑”**——用 **StackEdit**。

### 组合使用

很多资深 Markdown 用户会组合使用多个工具。常见的工作流程是：

1. 在 VS Code 或 Obsidian 中**写作**（用 Git 做版本控制）。
2. 与非技术同事合作时，在 Notion 或 Google Docs 中**协作**。
3. 需要精致的文档时，用 printmd **转换**成 PDF。

没有规定说只能选一个工具。

## 总结

最好的 Markdown 编辑器，就是最适合你工作流程的那一款。这份清单上的每个工具都有明确的长处，没有哪一个是放之四海而皆准的“最佳”。挑两三个符合你主要用途的工具，每个用上一周，让你的工作流程来做决定。

Markdown 的美妙之处在于文件可以随身携带。如果你从 Obsidian 起步，之后换到 VS Code，内容也会跟着你走。这就是纯文本带来的自由。
